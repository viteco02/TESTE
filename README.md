# Banco Ágape — Retiro REconectados 2027

App de banco do retiro. Moeda: **Agapix**.
- Login de **cliente**: saldo, extrato e número da conta.
- Login de **gerente**: cadastra pessoas, envia/retira Agapix (individual, por equipe ou para todos), ranking e extrato geral.

Servidor: Supabase (projeto `banco-agape`). Código web em `www/index.html`.
Cada push neste ramo gera um APK novo em *Releases* (GitHub Actions).
